# 타바타이머

_인터벌 트레이닝, 타바타 등 운동 세션 타이머 및 기록 서비스_

</div>

## 배경

인터벌 트레이닝이나 스트렝스 프로그램을 진행할 때, 다음의 필요성을 느꼈습니다:

1. 쉬는 시간을 일정하게 가져가고 싶다.
2. 일정한 박자에 맞춰 동작을 수행하고 싶다. ex) 러닝 중의 케이던스, 웨이트 트레이닝 중의 동작 템포
3. 운동 수행 시간과 쉬는 시간을 기록하여 다음 운동 때 참고하고 싶다.
4. 타이머 세팅을 저장하여 다음 운동 시에 활용하고 싶다.

타바타이머는 이를 해결하기 위해 제작된 타이머입니다.
